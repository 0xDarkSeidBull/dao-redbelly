# Platforms / Issuers to Introduce (RWA.xyz Step 3 — Data Collection)

RWA.xyz's process requires an introduction to *each* tokenization
platform issuing assets on the network, so they can collect Platform,
Issuer, and Asset reference data directly from them (Step 3 of
`ONBOARDING-CHECKLIST.md`). Below is what's independently confirmed
about each candidate found during this task's research — not an
exhaustive list, and not a substitute for the platforms confirming
their own current status before an introduction is made.

## 1. Raze Finance

- **What's confirmed:** A strategic partnership between Raze (a no-code
  RWA tokenization engine) and Redbelly Network, announced via press
  release (April 2025). Raze's platform handles token creation, issuance,
  and investor management; Redbelly provides the settlement/compliance
  layer.
- **Asset-class relevance:** General-purpose tokenization infrastructure
  — the platform itself, not a single named asset.
- **Source:** EIN Presswire / WJBF, April 11 2025 announcement.
- **Before introducing:** confirm the partnership is still active and
  get a named point of contact at Raze — press-release-era partnerships
  can lapse or change scope.

## 2. wisr Australia — "Freedom Trust"

- **What's confirmed:** Per Redbelly's own X account, wisr Australia's
  $250M Freedom Trust is live on-chain as part of the Reserve Bank of
  Australia's Smart ABS (Asset-Backed Securities) Pilot, built on
  Redbelly.
- **Asset-class relevance:** Structured credit / asset-backed securities
  — likely maps to RWA.xyz's "Private Credit" or "Institutional
  Alternative Funds" category rather than "Real Estate," despite the
  underlying assets — confirm the correct category with wisr directly
  rather than assuming from the name.
- **Source:** Redbelly Network's own X/Twitter account.
- **Before introducing:** this is a regulator-pilot program (RBA), so
  confirm wisr's own disclosure comfort level before RWA.xyz reaches out
  — pilot-program participants sometimes have communication constraints
  their commercial partners don't.

## 3. Hutly

- **What's confirmed:** Named by Redbelly's own blog as an example of an
  asset issuer managing properties on the network ("managing properties
  like Hutly" — Redbelly Network Blog, "Not Another RWA 101").
- **Asset-class relevance:** Real Estate — property management.
- **Source:** Redbelly Network Blog, March 20 2025.
- **Before introducing:** the blog reference is a passing example, not a
  dedicated announcement — verify Hutly is actually issuing tokenized
  assets on Redbelly today (vs. an earlier pilot or a forward-looking
  mention) before treating it as a confirmed Step-3 introduction.

## What's deliberately not on this list

Redbelly's own marketing repeatedly emphasizes being "purpose-built for
RWA issuers" in general terms, but this task did not find *additional*
named platforms beyond the three above with a specific, sourceable
claim attached. Padding this list with unconfirmed names would recreate
the exact problem flagged in Part 1 and Part 2 of this task — unsourced
claims. If more platforms exist, get their names from the Redbelly team
directly and add them here with the same sourcing discipline before the
Step 3 introductions are made.
