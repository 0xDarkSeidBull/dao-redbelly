**Longer description (for a profile body):**
Redbelly Network is built specifically for RWA issuers to create
on-chain registries and compose tokenized assets into structured
products, with network-wide verifiable-credential and KYC/AML
infrastructure rather than bolt-on compliance. Its consensus (DBFT) is
formally verified and leaderless. The network holds U.S. Patent
#12093247 for its "Superblock" scalability approach. Redbelly Mainnet
went live following a public Testnet phase (160,000+ unique accounts,
30M+ transactions, zero losses per Redbelly's own announcement).

**Backing / institutional ties:** University of Sydney, CSIRO's Data61,
Block8 (Sydney-based venture studio), Australian Research Council (ARC).
