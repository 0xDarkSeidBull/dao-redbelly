# Unstick Your RBNT: A Cross Chain Recovery Playbook
<img width="1800" height="1004" alt="task16logo" src="https://github.com/user-attachments/assets/afb51b6d-0c45-4488-b9f3-16dad602a61c" />


A community support guide for the four most common ways RBNT gets stuck: wrong network CEX deposits, wrapped RBNT showing zero value, quote unavailable errors bridging back to Redbelly Network, and stranded stablecoin transfers.

Every number in this guide (contract addresses, pool liquidity, price impact, bridge fees and timing) was checked live in August 2026, not pulled from documentation alone. Where something could not be verified, that is stated directly rather than filled in with a guess.

## What is in this folder

| File | What it is |
|---|---|
| `Unstick_Your_RBNT_Recovery_Playbook.pdf` | The full 13 page playbook, ready to read or print |
| `Unstick_Your_RBNT_Recovery_Playbook.docx` | The same playbook, editable |
| `playbook.md` | Plain markdown source, used to build the website |

## What is inside the playbook

1. Before You Bridge: how to avoid a wrong network deposit in the first place
2. Reference Tables: the verified wrapped RBNT contract addresses on every chain, plus live swap liquidity depth
3. Failure Mode 1: wrapped RBNT showing zero value or a swap that will not complete
4. Failure Mode 2: quote unavailable when bridging RBNT back to Redbelly Network
5. Failure Mode 3: USDC or USDT that appears stranded on Ethereum
6. Failure Mode 4: RBNT sent directly to an exchange on the wrong network

## A note on how to use this

This guide describes what was true at the time it was checked. Bridge routes, pool depth, and exchange recovery processes change. Treat the step by step instructions as durable and the specific numbers (fees, price impact, liquidity) as a snapshot, confirm current figures before acting on anything that matters to you.
